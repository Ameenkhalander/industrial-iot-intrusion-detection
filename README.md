# Intrusion Detection Model for Industrial IIoT

Machine learning inspired cybersecurity project for detecting suspicious activity in Industrial IoT environments.

## Features
- Detect abnormal traffic
- Input packet metrics
- Web dashboard
- Flask based application

## Tech Stack
Python, Flask, HTML, CSS

## Run

pip install -r requirements.txt
python app.py

http://127.0.0.1:5000
